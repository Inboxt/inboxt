# Getting help

If you have questions, run into issues, or want to share feedback, you’re welcome to reach out.

## Source Code and Community

For bugs, feature requests, or general discussion, please use our [GitHub repository](https://github.com/inboxt/inboxt).

GitHub is the central place to:

- Report bugs
- Suggest improvements
- Ask questions about self-hosting
- Follow development progress

## Support

As Inboxt is an open-source, self-hosted project, support is provided by the community on a best-effort basis via GitHub Issues and Discussions.
